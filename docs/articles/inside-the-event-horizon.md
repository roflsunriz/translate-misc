## 基調講演：ジャック・クラーク

さて、この度は大変丁寧なご紹介をいただき、誠にありがとうございます。お招きいただき、心より感謝申し上げます。このような機会を得られたことはこの上ない光栄です。まず始めに、私の関連する経歴を簡単にご説明したいと思います。私はただの人間です。この世に一人しかいない存在であり、この講演を行うまでの約40年間をかけて積み上げてきた経験があります。後ほど改めてこの経歴について触れさせていただきます。私のキャリア全体を通じて、常に取り組んできたのは、世界の未来にとって重要と思われる情報を見つけ出し、それを世界に伝えることでした。20年前、私はジャーナリストとしてデータセンター分野からキャリアをスタートさせました。その後、人工知能への強い関心から、2016年にジャーナリズムを離れOpenAIに参画し、さらに数年後にはAnthropicを共同設立しました。それ以来、私はAIシステムがいずれ非常に強力になり、国家の安全保障に影響を与え、地球の経済動向を変化させ、最終的には自らを構築する能力を獲得する可能性があることを、世界に向けて発信し続けてきました。

その瞬間がまさに訪れています。AIは今や国家の安全保障を変革しつつあるのです。AIは世界の経済動向をも変化させており、これまで数多くのセッションで議論されてきた通りです。同時に、AIは自らの発展にも寄与しています。多くの皆さんが既にご存知の通り、これはAIが世界を形作る数多くの不安定要因の一つとして追跡すべき重要な課題です。私が本日お話ししたいのは、AIが現在私たちが予想している以上のさらなる変革をもたらす軌道に乗っているという事実です。私たちはそれに応じて準備を整える必要があります。その理由についてもご説明いたします。長年にわたり、研究者やSF作家たちは、AIシステムが科学と技術の全体的な進歩の速度を大幅に加速させ、物事が非常に急速に進展することで、人間が追いつくのが困難になる未来を予測してきました。彼らはこれを「シンギュラリティ」と呼んでいます。そして私は、今年になってこの現象が実際に始まりつつあるという説得力のある証拠を得たと確信しています。

作家のヴァーナー・ヴィンジ（Vernor Vinge）は1993年に、この技術的特異点について予測を行いました。彼は次のように述べています。「人間を超える知性が進歩を推進するようになれば、その進歩の速度は飛躍的に加速するでしょう。実際、進歩そのものが、より短い時間軸でさらに高度な知性を持つ存在を生み出さない理由はないように思われます」。さらに彼は、この特異点を、私たちのモデルを破棄し、新たな現実が支配する転換点として描写しました。まさにこの特異点は現在進行中です。その影響は私たちの生活のあらゆる側面に及ぶでしょう。しかし最も重要な意味合いは、実にシンプルなものです。今後数年間で、AIだけでなく、科学全体の進歩のペースそのものが加速することを私たちは予期すべきです。この変化は混乱と方向感覚の喪失をもたらし、同時に莫大な富を生み出す可能性とともに、大きな危険も伴うでしょう。そこで本日は、後者の点を軽視することなく、最初のポイントに焦点を当ててお話ししたいと思います。私は急速なAI進歩の恩恵と、それを共有するために私たちが取るべき行動について論じる予定です。人類がAIから得る恩恵の多くは、科学分野からもたらされます。AI駆動型の科学的発明は、世界経済の進路を転換させ、各国のインフラ計画と整備方法を変革し、私たちをより健康にし、愛する人々と過ごす時間を増やすことを可能にするでしょう。同時に、これは私たちに、技術の継続的な発展に関する深い哲学的問いを投げかけることにもなります。そこで私の主張をさらに展開したいと思います。過去半世紀にわたり、ほとんどの国では研究者の生産性が低下している一方で、研究者の数は急速に増加しています。アイデアや発明を見つけることがますます困難になっているように見えます。しかし、ここに重要な変化が生じています。私たちは現在、人間の労働の特定の側面を強化・拡張・自動化する能力を備えたAIシステムを構築しました。この変化は特にソフトウェア開発分野で顕著に現れており、AIシステムは今や世界のソフトウェアエンジニアの大多数よりもはるかに高度で効率的です。その結果、ソフトウェア開発の分野は大きく変化しています。一人の人間が、想像するあらゆるもののソフトウェアを記述できるようになり、以前はチーム全体の人間によって数ヶ月かかっていたような成果を生み出すことが可能になりました。私たちはこの現象の具体的な証拠をAnthropic社の中で目にしています。ご覧の通り、当社の研究者は創業以来の最初の4年間と比較して、ほぼ10倍の量のコードを生産しているのです。そしてこのコーディング能力の向上は、基本的にAIの能力向上と直接的に相関しています。ただし注意すべき重要な点は、これらの新しいAI能力が新たな課題をもたらすということです。コーディングの改善により、AIシステムはサイバーセキュリティとサイバー攻撃の両方において大幅に進化しており、私たちが耳にしているように、各国はこれらの強力な能力をサイバー防衛システムの配備に活用する競争を繰り広げています。一方で悪意ある行為者は、これらのシステムを利用してハッキングを行うために競い合っています。注目すべき重要な点は、これらの事象が相互に切り離せない形で結びついているということです。コーディングのような一般的な分野におけるAIシステムの進歩は、サイバーセキュリティのような国際的に重要な領域において、正と負の両方の影響をもたらすのです。

これは今後の展開を予感させる兆候であり、新たな能力の獲得と新たな課題の出現を示しています。これらの能力はプログラミング分野に留まらず、科学やロボット工学の分野にも波及し始めています。実際、この現象はすでに始まっており、インターネットやスマートフォン、人工知能といった全く新しい汎用技術の登場のように、世界経済の重要な特性が変化する可能性を秘めています。例えば、イノベーションの速度や、インターネットや人工知能のように全く新しい産業を生み出すような技術の出現頻度などが変化し得るのです。私がこのように考える理由は何か、またこの考えを皆さんにも納得していただくために私は何をすべきでしょうか？2026年、私たちはAIシステムが最先端科学研究を行える可能性を示す最初の兆候を得ました。数学分野では、AIシステムがナビエ-ストークスのミレニアム懸賞問題やヤコビアン予想といった長年未解決だった数学問題の解決策を提案したり、複数の未解決エルデシュ問題に取り組んだりしています。

多くの場合、AIシステムが核心的な洞察を発見し、それが解決策の実現を可能にしています。生物学分野では、研究者たちがAIを活用してゼロからウイルスを設計したり、新たな薬剤候補を特定したりしています。現在すでに、AIシステムが大部分を設計した薬剤が臨床試験段階に入っています。また、ロボット工学分野では、AIシステムが実験機器を自律的に操作する能力をますます高めており、これにより生物学から材料科学に至るまでの分野で実験をさらに自動化し、バッテリーや燃料電池の開発などにおいてより迅速な進歩が可能になっています。個々の事例としてはそれぞれ興味深いものですが、これらの根本的な共通点は、すべて同じ基盤技術に基づいている点にあります。そしてほとんどの応用事例において、同じ単一の基盤的フロンティアモデルが存在しているのです。現在ではClaude、ChatGPT、GeminiといったAIシステムが、複数の科学分野の最先端研究を遂行できる単一の存在となっています。

私たちはバーチャルな博学者を手にしました。さらに定量的な証拠も存在します。その一つが「Humanity's Last Exam（人類最後の試験）」と呼ばれるAIシステムのスコアリングです。私はこの名称を選んだわけではありません。この不吉な名前の試験は、AIシステムが過去数年間に様々な分野の困難で多様な科学課題において達成した画期的な進歩を受けて開発されたものです。試験内容は化学、コンピュータサイエンス、数学、古典文学、生態学など多岐にわたります。2025年1月に試験が開始された時点では、最高得点を獲得したAIシステムのスコアは8%でした。今週現在、最高得点を記録したのはClaude Opus 5.5で67.7%です。もう一つの例として、2024年11月にリリースされた「FrontierMath」試験があります。これはAIシステムが数百の難解な数学問題を、専門の数学者たちによって選定・評価された問題セットとして解決する能力を評価するものでした。試験開始時点では、最高得点を獲得したシステムのスコアは2%でした。

現在、彼らのスコアは94%に達しています。より広範に言えば、私が強調したいのは、この現象があらゆる分野で観察されているという点です。私のコンピュータには、ここ1週間の間に作成した100のグラフデータが保存されています。私は講演を行う前に今朝これらをダウンロードしました。科学の様々な分野からデータを抽出すると、同じパターンが繰り返し現れることがわかります。進歩は加速しており、この2年間でその加速はさらに顕著になっています。時にはわずか1年という短期間でも見られる現象です。そこでこの証拠に関する議論を、ある興味深い事例で締めくくることにします。先週発表された論文が、この最新の事例として私たちのもとに届きます。これは私が趣味で行っている研究活動の一環です。私は学術論文を読むことを趣味としており、講演の準備の合間にこれを行っています。今回の論文は「TheoPhysEval」と呼ばれ、AIシステムが理論物理学の未発表問題を解決する能力を評価した研究です。論文中の50の問題は、世界中の物理学者たちによって収集されました。これらの問題は未発表の研究成果であり、驚くべきことに、AIシステムは非常に高いスコアを獲得しました。

しかし驚くべきは、そのスコア獲得の経緯です。ここでこのテストの著者の一人であるインドの物理学者Suvrat Raju氏の言葉を引用します。同氏は自身のFacebookでこの研究結果についての考察を投稿しています。「AIの支援なしに、最終問題集の相当部分を解ける人を私は一人も知りません」と同氏は述べています。初期評価では、GPT-6 Astraのスコアは80年代後半に達し、Claude Opus 5.5がそれに極めて近いスコアを示していました。しかしモデルが誤りを犯した可能性を調査し始めると、特にGPT-6 Astraは自らが正しいと主張し、人間が提供する解答に誤りがあると主張しました。専門家たちを再調査したところ、複数の事例で、専門家たちが計算の奥深くに潜んでいた微妙な誤りを発見したことが判明しました。専門家たちが解答を修正するにつれ、GPT-6 Astraのスコアは徐々に上昇し、最終的には98%という高い値に達しました。50問中49問が正解という結果でした。

この事実について考えてみてください。世界有数の科学専門家たちが、AIが決して知り得ない問題を作成したテストを構築したのです。そしてこのテストをAIに実施したところ、AIは単に良好なスコアを獲得しただけでなく、人間たちが取り組んだ問題の誤りを発見することでさらに高いスコアを達成しました。映画でよくある展開として、通常は物語の中盤あたりで、若い主人公が師匠に対して、世界に出て自立して成功するだけの能力があることを最終的に証明する場面があります。教師が生徒となり、生徒が教師となるという物語の定型パターンが、まさに先週起こったのです。ですから、私がこの話をしている理由、そしてAIシステムが科学分野でますます進歩していることがなぜ重要なのかを考えてみてください。私は、真のフロンティアサイエンス、すなわち知識のフロンティアを拡大するような画期的な発見を行う能力が、AIの能力における最後のフロンティア、すなわち創造性のテストとなっているからだと考えています。

私の見解では、AIシステムが創造的に問題解決を行い、科学分野で成功を収められるようになれば、これはAIが多様な分野に応用可能であることを示す重要な兆候と捉えるべきです。特にAI研究そのものへの応用は、イノベーションに爆発的な影響を与える可能性があります。AIシステムが科学分野で進歩すれば、それは将来の経済成長を強く牽引し、ひいては各国や国民がこの潮流から利益を得るための基盤構築を今日行うべきだということを意味します。では、成長について議論しましょう。主要な成長源の一つは、新たなアイデアを生み出す研究活動です。また、人類の知的資本、つまり世界中で疑問を抱き、科学的研究を行い、世界を前進させる人々の存在も、成長を促進する重要な要素です。しかし、経済学者が指摘するように、優れたアイデアの獲得は次第に困難になっており、画期的な成果を得るためのコストは上昇し続けており、同じペースで前進し続けるためには研究投資を継続的に増加させる必要が生じています。

現在私たちはこの決断の結果に直面しています。今日の世界では、データセンターのキャパシティは米国、中国、そして中東地域に集中しており、さらに中東地域でも急速に拡大しています。また、サプライチェーンも集中化が進み、競争が激化する中で価格が上昇しています。データセンターの整備は依然として重要ですが、これはAIの継続的な進化がもたらす経済的・科学的革命の第一段階に過ぎません。今後さらに構築すべきものがあり、私はより多くの国々がこの機会に参加できると信じています。なぜなら、次のAI革命の段階は、AIシステムが科学的実験を実施し、ロボットを操作するなど、物理的世界に直接関与することに焦点を当てたものだからです。したがって、計算能力や電力の場合と同様に、私たちは世界規模でより高度な科学機器やロボットシステムを必要としており、そうしなければ再び能力不足に陥り、歴史が繰り返されることになるでしょう。

したがって、今後の進展を活用するためには、今こそ能力構築に取り組む必要があります。ユネスコの推計によれば、世界には約1,000万人の科学者が存在しています。たとえ1,000万人の科学者しかいなくても、現代の研究を監督する人材も、材料科学分析を行う研究室も、新薬の開発・試験を行う生物学研究室も、いずれも不足しています。さらに、宇宙や地球上で実施したい実験に必要な大規模科学機器も十分ではありません。では、現在の約1,000万人の科学者が10億人の仮想科学者を指揮するようになったら、何が起きるでしょうか。10億人規模の科学者が存在する世界が、予測可能な形で目前に迫っています。私たちはこの未来に向けて準備を整える必要があります。もし準備が整えば、AIシステムの知能を人類全体の利益へと転換する上で有利な立場に立つことができます。具体的には、より長く健康的な生活、より多くのエネルギー、より多くの食料、より多くの富を実現する可能性が高まります。データセンターの場合と同様、このサプライチェーンを構築・発展させた国々が最も大きな恩恵を受けることになるでしょう。
